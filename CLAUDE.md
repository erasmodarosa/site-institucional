# Sobre este projeto

Landing page institucional (estática, HTML/CSS/JS puro, sem build) do app **Controle
Pré-Moldado** — ver estrutura e próximos passos combinados em [README.md](README.md). Erasmo
(dono do negócio, não é programador) trabalha em dois PCs diferentes, cada um clonando este
mesmo repositório do GitHub (`erasmodarosa/site-institucional`), então este arquivo é o que
carrega contexto entre as máquinas — mantenha atualizado quando um acordo de trabalho mudar.

Publicado em `controlepremoldado.com.br` via Vercel (projeto `site-institucional`), **conectado
ao GitHub desde 2026-09-11** — todo push em `main` dispara deploy automático de produção nesse
domínio. Antes disso o domínio servia um placeholder antigo "Site em construção", deployado
manualmente e nunca ligado ao git; se o domínio um dia parecer "voltar" a um estado antigo,
confira primeiro se a conexão Git do projeto na Vercel ainda está ativa antes de mexer no código.

O app de verdade (Expo/React Native Web + Supabase) é um projeto **separado**, em
`erasmodarosa/CONTROLE-PR--MOLDADO` — este repositório não compartilha código com ele.
